## 2024-05-24 - Context-Aware Alt Text in Educational Markdown
**Learning:** In purely text-focused educational Markdown manuscripts, purely visual image alt text or verbatim repetition of the surrounding narrative degrades UX for screen reader users by missing the author's rhetorical intent and creating redundancy.
**Action:** Always synthesize the surrounding narrative arguments into a concise, informative description for image alt text to properly convey the pedagogical purpose of the image.
