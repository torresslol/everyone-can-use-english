## 2024-05-23 - Context-Aware Alt Text for Narrative Arguments
**Learning:** In narrative-heavy Markdown documents (like the "Everyone Can Use English" book), images are frequently used as rhetorical devices rather than mere visual illustrations. Purely visual alt text fails to convey the point the author is making.
**Action:** When adding alt text to such documents, synthesize the surrounding text to describe the image's rhetorical purpose, avoiding verbatim repetition while ensuring screen reader users grasp the core argument.
