## 2024-06-06 - Meaningful Alt Text
**Learning:** Adding generic alt text like "Illustration" to images is an accessibility anti-pattern because screen readers already announce the image role. It's better to provide descriptive context or leave it empty for decorative images. Also, indiscriminate whitespace stripping can break Markdown line breaks.
**Action:** When adding alt texts to markdown manuscripts, only add them when providing meaningful context extracted from surrounding text. Ensure modifications stay within the 50 lines limit and avoid unprompted whitespace changes.
