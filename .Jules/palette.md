## 2026-03-06 - Context-aware Alt Text for Narrative Arguments
**Learning:** In long-form Markdown prose, alt texts for images should not merely describe the visual content (e.g., "A graph of pupil dilation" or "A cat in an experiment"), but should instead explain the image's role in the surrounding narrative argument (e.g., "猫和猴子视觉剥夺实验，说明“关键期”概念").
**Action:** Always derive alt text from the surrounding context and argument rather than purely visual properties when adding accessibility to long-form prose.
