## 2024-05-24 - Purely Markdown Architecture
**Learning:** This repository consists entirely of Markdown files deployed as static content. Application-level codebase optimizations (e.g., React, DB, API, or Javascript optimizations) do not apply here. Upgrading HTTP links to HTTPS, while technically reducing redirect latency, is strictly required for CI passing rather than an optional micro-optimization.
**Action:** When tasked with application performance optimization in this purely Markdown repository, determine that no suitable code-level optimizations exist and stop without creating a PR.
