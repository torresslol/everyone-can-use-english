## 2024-05-18 - Context-Aware Alt Text for Educational Markdown
**Learning:** Alt text in rhetorical, educational Markdown content must capture the surrounding narrative argument (e.g., explaining that an uninjured arm is restrained so the injured arm can receive recovery training), rather than being purely visual descriptions.
**Action:** Always extract and analyze surrounding textual context before generating alt text for images in book manuscripts to ensure narrative alignment.
