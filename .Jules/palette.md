## YYYY-MM-DD - Contextual Alt Text for Software Instructions
**Learning:** When adding alt text to images in instructional manuals, the surrounding instructional text itself is the most accurate source for the alt text, as it describes exactly what the user is supposed to look for in the screenshot.
**Action:** Prioritize extracting specific phrases from the text immediately preceding or following an image to construct precise, non-redundant alt text for software interface screenshots.
