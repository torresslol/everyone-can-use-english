## 2026-06-24 - Interactive Pedagogical Images in Markdown
**Learning:** This manuscript frequently uses images to pose pedagogical, interactive questions to the reader (e.g., asking which arm is injured based on visual cues before revealing the answer).
**Action:** When adding alt text to images in this manuscript, ensure the text describes the visual state accurately without prematurely spoiling the answers to the pedagogical questions posed in the subsequent text.
