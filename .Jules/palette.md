## 2026-07-01 - Add Alt Text to Pedagogical Markdown Images
**Learning:** In a Markdown-based book with pedagogical images, adding descriptive alt text improves accessibility for screen readers. However, care must be taken to describe the visual state factually without prematurely spoiling answers to pedagogical questions in the subsequent text.
**Action:** When working on Markdown manuscripts with images, always add concise, descriptive alt text to `![]()` tags using explicit byte manipulation to avoid regex errors.
