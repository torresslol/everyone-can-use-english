## 2024-05-15 - Context-Aware Alt Text for Rhetorical Images
**Learning:** In purely Markdown repositories where images serve narrative or rhetorical arguments rather than literal demonstrations, generic visual descriptions (e.g., "a photo of a cat") fail screen reader users. The true accessibility value lies in conveying the author's rhetorical intent.
**Action:** When adding alt text to Markdown narratives, derive the description from the surrounding context to explain *why* the image is there, matching the repository's primary language (Chinese).
