## 2024-05-24 - Context-Aware Alt Text for Educational Manuscripts
**Learning:** For an educational manuscript formatted in Markdown, a generic visual description in image alt text is often insufficient for accessibility. The core UX value lies in conveying the underlying argument or narrative that the image supports (e.g., explaining why a specific scientific experiment proves neural plasticity, instead of simply describing "a cat with sewn eyes"). Contextual integration is critical for screen reader users to grasp the educational content.
**Action:** When working on similar educational repositories, prioritize extracting the narrative context from surrounding paragraphs and using that to construct the alt text, rather than relying strictly on literal visual descriptions of the image.
