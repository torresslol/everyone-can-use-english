## 2024-05-12 - Accessibility Guideline: Alt text and Interactive Guessing Games
**Learning:** When crafting alt text for images within a narrative that asks the user a question about the image (e.g. "which arm is injured in the image below?"), do not preemptively reveal the answer in the alt text. This degrades the experience for screen reader users by spoiling the guessing game.
**Action:** The alt text should either reiterate the question or provide contextual information that allows the user to participate in the narrative experience without spoiling it.
