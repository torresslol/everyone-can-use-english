## 2024-05-24 - Context-Aware Alt Text for Narrative Images
**Learning:** Alt text in narrative-driven Markdown content (like chapters in a book) should synthesize the surrounding rhetorical context rather than providing a pure visual description, to prevent redundant and degraded UX for screen reader users.
**Action:** When adding alt text to images in manuscript chapters, derive the description from the preceding arguments and context instead of verbatim repetition or purely visual descriptions.
