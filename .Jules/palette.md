## 2026-04-03 - Context-Aware Alt Text for Markdown Books
**Learning:** In narrative-heavy Markdown documents, image alt text must reflect the rhetorical purpose and surrounding context rather than purely visual descriptions. This significantly improves accessibility by conveying the actual argument the image supports.
**Action:** When adding alt text to images in manuscripts, always read the surrounding paragraphs and construct alt text that explains *why* the image is there, not just *what* it looks like.
