## 2026-06-21 - Meaningful Alt Text for Book Illustrations
**Learning:** The markdown chapters in this manuscript consistently omit alt text for illustrations, relying entirely on surrounding body text for context. This creates a confusing experience for screen reader users who encounter unidentified image elements before reaching the explanation.
**Action:** Always extract the concise, core subject of the image (e.g., the specific object like a cave painting) from the adjacent text to use as alt text, avoiding verbatim repetition of long sentences.
