## 2026-06-30 - Educational Image Alt Text
**Learning:** The manuscript for 'Everyone Can Use English' uses images to pose interactive, pedagogical questions. Adding alt text must describe the visual state accurately without prematurely spoiling the answers to these questions in the subsequent text.
**Action:** When adding alt text to educational material, review the surrounding context to ensure the description is factual to the visual without giving away the lesson's answer prematurely.
