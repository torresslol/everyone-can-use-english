## 2026-06-15 - Add missing alt texts to Markdown images

**Learning:** Images in Markdown narratives without alt texts create an inaccessible experience for screen reader users, especially when they form part of a 'guessing game' or are essential to the narrative context. If alt text spoils the interactive questions (e.g. revealing which arm is injured), it severely degrades the user experience.
**Action:** Always add concise alt text to images based on the surrounding context without preemptively spoiling any interactive narrative elements or just copy-pasting the adjacent body text verbatim.
