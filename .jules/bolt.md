## 2024-05-18 - Cloudflare Workers CI Markdown link checker performance constraints
**Learning:** This repository is deployed via Cloudflare Workers. Its CI pipeline runs a strict Markdown link checker. When external HTTP links or shortlinks (like is.gd) are present, it forces server-side redirects which increases network latency. The CI build can also fail or timeout if it encounters unsecure HTTP URLs or dead links, or Markdown links with leading spaces. Because this project consists entirely of Markdown files, application-level architectural optimizations (like React memoization or DB indexing) do not apply. Replacing HTTP links with their resolved HTTPS destinations serves as the sole applicable performance optimization, improving build reliability and client-side resolution latency.
**Action:** Always upgrade all external `http://` URLs in Markdown files to `https://`. Resolve any URL shorteners (e.g. `is.gd`) directly to their final HTTPS destinations. Also eliminate leading spaces inside markdown link parentheses (e.g. `( http://` to `(https://`) to prevent CI parser errors.
