## 2024-04-29 - Context-Aware Alt Text for Narrative Images
**Learning:** When adding alt text to images in a narrative context, especially when the text poses a question about the image to the reader (e.g., asking which arm is injured), the alt text must avoid spoiling the answer to preserve the interactive experience for screen reader users.
**Action:** Always review surrounding text for questions or interactive prompts before writing alt text, ensuring the description supports the rhetorical purpose without giving away intended surprises.
