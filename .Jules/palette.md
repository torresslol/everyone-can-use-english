## 2025-01-20 - Context-Aware Alt Text in Markdown
**Learning:** In narrative-heavy Markdown documents without standard UI components, the primary accessibility vector is image alt text. Simply describing the image visually degrades the screen reader experience; the alt text must synthesize the surrounding rhetorical argument to be meaningful.
**Action:** When adding alt text in similar narrative contexts, I will derive the description from the surrounding arguments and avoid verbatim repetition of the text.
