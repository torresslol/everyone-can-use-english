## 2026-07-04 - Pedagogical Image Descriptions
**Learning:** When adding alt text to images used for interactive or pedagogical quizzes (e.g., asking the reader a question about the image), describing the visual state accurately without prematurely spoiling the answer requires carefully balancing visual description and pedagogical intent.
**Action:** Always read the surrounding text to understand if an image serves as a question prompt before drafting alt text, ensuring the description perfectly matches the sighted experience without giving away the answer.
